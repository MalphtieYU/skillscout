# Privacy Policy

Last updated: 2026-08-07

SkillScout is an open-source, skills-only Codex plugin. It does not operate a separate service, collect telemetry, host a database, or independently receive user content.

SkillScout may recommend using a connected Codex capability such as GitHub, Figma, Google Drive, Gmail, Calendar, or an MCP server when a user explicitly requests work with a real external source. Any connection, authentication, data access, and tool execution are handled by the user's Codex environment and the relevant third-party service.

Users should review each connected tool's permissions before use and should not provide secrets, credentials, or sensitive personal data in prompts. SkillScout's guidance is designed to favor native work and the least access needed for a task.

For security reports or privacy questions about this repository, open a GitHub issue without including sensitive data.
