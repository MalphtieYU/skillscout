# Continue After Recommendation

SkillScout should reduce the time between a user request and useful work. After the short startup decision, continue immediately.

## Native Only

Begin the requested work directly: write the content, analyze the pasted data, fix the supplied code, create the plan, or build the initial page.

## Plugin recommended but not installed

Give conservative installation guidance, then complete work that does not need the integration: clarify requirements, draft a project plan, create file structure, write initial code, or prepare prompts. Do not wait for the user to compare plugins.

## Plugin required but not installed

State briefly that access is needed for the real external source or action. Provide the installation or preparation checklist, then complete the non-sensitive setup and describe the first action after access is available.

## Plugin installed

Use the available tool context and proceed with the requested task. Do not repeat the selection process.

## Permission required

State what access or write action matters and what could go wrong. Continue planning, drafting, analysis, or other non-sensitive work. Ask only before the action that actually needs permission or confirmation.
