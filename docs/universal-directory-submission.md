# Universal Plugins Directory Submission

SkillScout is already distributed through the public GitHub marketplace. Publishing it in the universal ChatGPT/Codex Plugins Directory is a separate OpenAI review workflow.

## Ready in this repository

- Skills-only plugin package: `plugins/skillscout/`
- Public marketplace manifest: `.agents/plugins/marketplace.json`
- Public source repository, README, Simplified Chinese README, support, privacy, and terms pages
- Plugin logo, starter prompts, and 20 behavior test cases
- More than the required five positive and three negative test scenarios in `docs/test-cases.md`

## Publisher actions still required

1. Sign in to the OpenAI Platform organization that will own the listing.
2. Ensure the submitter has **Apps Management: Write** permission, or is an organization owner.
3. Complete individual or business developer identity verification for that organization.
4. Decide the countries or regions where the plugin may be available. Select only places where the publisher, support process, privacy notice, and terms are ready.
5. Open the [plugin submission portal](https://platform.openai.com/plugins), create a **Skills only** submission, and upload the final `plugins/skillscout/` package.
6. Add the listing details, public URLs, starter prompts, and test cases from this repository; review all policy attestations and submit for review.

## Important boundary

Submitting starts OpenAI review; it does not immediately make the plugin public. After approval, the publisher chooses when to publish from the portal. Do not claim universal-directory availability until that approval and publication occur.
