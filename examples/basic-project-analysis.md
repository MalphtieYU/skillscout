# Basic Project Analysis

## User

I want to build a personal portfolio website. Which Codex plugins do I need?

## SkillScout Recommendation

## 1. Project Understanding

You want to build a personal portfolio website, probably with pages such as Home, Projects, About, and Contact.

## 2. Does this project need plugins or skills?

Optional enhancement only.

Codex can usually build a simple portfolio website with native coding abilities. Extra tools only become useful if you need design import, deployment, browser QA, or image generation.

## 3. Recommended Tool Stack

| Tool / Skill / Plugin | Priority | Why it helps | Required or optional | Chinese explanation |
| --- | --- | --- | --- | --- |
| Native Codex coding | Must-use | Builds the website files directly | Required | 直接让 Codex 写网页代码即可 |
| Browser / Web testing | Optional | Checks responsive layout in a real browser | Optional | 用来检查网页在浏览器里的效果 |
| Figma / Design | Optional | Helpful if you already have a design mockup | Optional | 如果你有设计稿才需要 |
| Deployment | Optional | Useful when you are ready to publish | Optional | 网站上线时再考虑 |

## 4. Tools You Probably Do Not Need

Slides, spreadsheets, PDF tools, email, calendar, and automation are not needed for the first version.

## 5. Best Workflow

1. Ask Codex to build the portfolio locally.
2. Review layout and content.
3. Add browser testing if the site has responsive issues.
4. Add deployment tooling only when ready to publish.

## 6. Copy-ready Codex Prompt

```text
Build a simple responsive personal portfolio website with Home, Projects, About, and Contact sections. Use native Codex coding first. Do not add plugins unless a specific need appears.
```

## 7. Questions Before Starting

1. Do you want a static HTML site or a React app?
2. Do you already have design references?
3. Where do you want to deploy it?
