# Design Project

## User

I need to turn a Figma design into a responsive React website.

## SkillScout Recommendation

## 1. Project Understanding

You want to convert an existing Figma design into working responsive React code.

## 2. Does this project need plugins or skills?

Strongly recommended.

Figma access is very useful because the task depends on design structure, layout, typography, and assets.

## 3. Recommended Tool Stack

| Tool / Skill / Plugin | Priority | Why it helps | Required or optional | Chinese explanation |
| --- | --- | --- | --- | --- |
| Figma / Design | Strongly recommended | Reads design context and assets | Optional but important | 用来读取 Figma 设计稿和组件信息 |
| Native Codex coding | Must-use | Implements the React app | Required | 用来编写 React 代码 |
| Browser / Web testing | Optional | Verifies responsive behavior | Optional | 用真实浏览器检查适配效果 |
| GitHub | Optional | Useful if the app lives in a repo or needs a PR | Optional | 如果要提交代码或开 PR 才需要 |

## 4. Tools You Probably Do Not Need

PDF, slides, spreadsheets, email, and calendar tools are not relevant.

## 5. Best Workflow

1. Use Figma to inspect the target frame or component.
2. Implement the React page using existing project patterns.
3. Run local browser checks for desktop and mobile.
4. Use GitHub only if you need repo automation or a pull request.

## 6. Copy-ready Codex Prompt

```text
Convert this Figma design into a responsive React implementation. Use Figma design context for layout and assets, then verify the result in a browser. Keep the implementation consistent with the existing codebase.
```

## 7. Questions Before Starting

1. Can you provide the Figma node URL?
2. Which React framework does the project use?
3. Should the output match the design exactly or adapt to an existing design system?
