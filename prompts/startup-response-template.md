# SkillScout Startup Response Template

Use exactly one of these compact patterns, then continue the user's task immediately.

## A. No plugin needed

```text
不推荐使用插件。
原因：{Codex 原生能力足够，或插件会增加不必要复杂度的原因。}
执行方式：直接使用 Codex 原生能力继续完成项目。
```

## B. One best plugin

```text
推荐使用：{plugin_name}
原因：{why this is the most valuable tool for the actual input or output.}
执行方式：我会按 {plugin_name} + Codex 原生能力继续完成项目。
```

Add a verified install card only when registry data contains a real installation route. Then continue the task.

## C. Minimal required pair

```text
推荐使用：{primary_plugin} + {secondary_plugin}
原因：{why both are required, with the primary tied to the core input or output.}
执行方式：我会按这个最小工具组合继续完成项目。
```

## D. Information is insufficient, but work can start

```text
暂不推荐插件。
原因：当前信息不足以判断具体插件，但可以先用 Codex 原生能力启动项目。
执行方式：我会先完成可确定部分，并在遇到真实文件、仓库、设计稿或外部服务需求时再提示插件。
```
